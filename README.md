**HOUSE PRICE PREDICTION SYSTEM**

A simple responsive web app that estimates house prices based on city, area, bedrooms, and property age.

**FEATURES**

* City-based price estimation
* Live price calculation
* Input validation
* Responsive dark-mode UI
* INR currency formatting

**PROJECT STRUCTURE**

```text
house-price-predictor/
├── index.html
├── style.css
└── README.md
```

**RUN**

Open `index.html` directly in a browser or use VS Code Live Server.

**FORMULA**
Price = (Area × City Rate)
        × Bedroom Factor
        × Age Depreciation
```

**TECH STACK USED**

HTML, CSS, and JavaScript.
